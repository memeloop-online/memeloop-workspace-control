# 设置

控制台只有一个 **设置** 入口，合并个人偏好与管理功能。旧的
`#administration` 链接仍可打开设置。

![CI 浏览器截取的统一设置，使用脱敏 MWC Demo 数据](/img/screenshots/settings-desktop.png)

本页截图均由 CI 浏览器使用脱敏演示数据生成，不包含生产账号或密钥。

## 查找设置

先选 **个人**、**组织** 或 **系统**，再按标题、说明或相关词搜索。搜索会
筛选每个设置区块，而不是只匹配整个分类。分类与结果只显示当前角色及 API
密钥 scope 有权访问的区块；未显示的管理区块可能需要额外权限。没有匹配项时
会显示空结果。

![搜索结果仅显示外观与语言区块](/img/screenshots/settings-search.png)

个人设置包含个人资料、外观（主题与语言）和 API 密钥。
组织分类包含当前组织选择、用户与角色及其他可访问的组织级控制；系统管理员可查看系统级管理功能。
管理能力及对应 REST 端点见[设置中的管理功能](./administration.md)。

## 再次复制 API 密钥

在 **个人 → API 密钥** 中对自己的密钥点击 **复制**，无需先选择组织。只要保存过明文，刷新
页面后仍可再次复制。列表仅返回摘要；仅在明确点击复制时获取密钥值，请将
其保存到密码管理器。获授权的管理员可在 **组织 → 用户与角色 → 凭据配置**
中复制其他用户已保留明文的密钥，权限规则与密钥管理一致。

![脱敏演示中的个人 API 密钥摘要，不显示密钥明文](/img/screenshots/user-api-keys.png)

旧的仅存哈希的密钥无法恢复明文。请主动创建替换密钥，更新使用方后吊销
旧密钥；系统不会自动轮换。

## 注入设置

工作区注入项包括**环境变量与文件**，也支持 SSH 公钥；它们与 API 密钥
分别管理。作用域与覆盖规则见[环境变量与文件](./credentials-and-files.md)。
