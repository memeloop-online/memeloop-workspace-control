# 常见问题

## 为什么我不能用自己的镜像创建工作区？

镜像默认拒绝。系统管理员必须先通过管理控制台或
`PUT /api/v1/admin/images` 放行镜像，模板才能引用它。

## 为什么我完全无法创建工作区？

要么没有启用的模板，要么配额已用尽。请联系组织管理员；组织与用户两个
层级都有配额。

## 轮换了密钥之后需要重建工作区吗？

不需要。注入项在工作区启动时解析。在对应作用域更新注入项并重启工作区
即可生效。

## 工作区创建者能排除组织级凭据吗？

只有未锁定的注入项可以。锁定的组织级注入项始终注入；未锁定项可在创建时
通过 `organization_injection_refs` 取消选择。

## API 密钥之后还能找回吗？

可以，前提是保留了明文。本人在 **设置 → 个人 → API 密钥** 中点击 **复制**，
刷新后也可再次复制；列表本身只返回摘要。获授权的管理员可在 **设置 → 组织
→ 用户与角色 → 凭据配置** 中复制其他用户已保留明文的密钥。历史仅存哈希
的密钥无法反推，请主动创建替换密钥；系统不会自动轮换。

## 端口映射会把我的应用暴露到公网吗？

不会。每个映射都要求一次性启动交换和由网关 external-auth 对控制面校验的
会话 cookie。删除映射会立即使现有会话失效。

## 完整的 API 契约在哪里？

每个部署提供 `GET /api/v1/openapi.json`。[API 参考](./api.md) 概述了集成
模型。

## 不 fork 平台能扩展它吗？

可以。[插件](./plugin-development.md)能执行创建策略、拦截 API 请求、添加
API 路由并渲染控制台 UI 界面，全部通过版本化 WIT 接口完成。
